# Становление Руси - RPG

Текстовая RPG-игра о становлении России от объединения славянских племен до освобождения от монгольского ига.

## Описание

Вы играете за молодого дружинника, который проходит через ключевые моменты русской истории:

- **Глава 1: Киевская Русь (9-10 века)** - Объединение племен, освобождение от хазарской дани
- **Глава 2: Расцвет (10-11 века)** - Крещение Руси, дипломатия с Византией
- **Глава 3: Монгольское нашествие (13 век)** - Борьба с Золотой Ордой
- **Глава 4: Возрождение (14 век)** - Куликовская битва

## Особенности

- Боевая система с характеристиками (здоровье, атака, защита)
- Система уровней и опыта
- Исторические враги и персонажи
- Квестовая система с сюжетными заданиями
- Инвентарь с оружием и броней
- 4 главы истории России

## Установка

```bash
# Установка зависимостей
npm install

# Сборка проекта
npm run build

# Запуск игры
npm start
```

## Как играть

После запуска игры вы увидите главное меню с опциями:

1. **Просмотреть квесты** - Выбрать и выполнить сюжетные квесты
2. **Отправиться в путешествие** - Случайная встреча с врагом
3. **Инвентарь** - Просмотр предметов
4. **Отдохнуть в таверне** - Восстановить здоровье за золото
5. **Информация о главе** - Узнать об истории и прогрессе
6. **Выход** - Завершить игру

## Игровая механика

### Боевая система
- Пошаговые бои с врагами
- Урон рассчитывается на основе атаки и защиты
- Победа дает опыт и золото

### Прогресс
- Накапливайте опыт для повышения уровня
- С каждым уровнем улучшаются характеристики
- Выполняйте квесты для продвижения по главам
- Собирайте золото для покупок и отдыха

### Квесты
- Каждая глава содержит уникальные квесты
- Квесты открываются по мере прогресса
- Награды включают опыт, золото и предметы

## Враги

Игра включает исторических противников:
- Хазарские воины
- Печенеги и половцы
- Монгольские захватчики
- Литовские рыцари
- Боссы: Хан Мамай и другие
